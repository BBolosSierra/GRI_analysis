### Glasgow Royal Infirmary (GRI) data analysis

Retrospective I-III colorectal cancer cohort from the Glasgow Royal Infirmary (n = 724). The aim of the analysis is to find predictors of colorectal cancer recurrence after curative surgery. A particularity of this cohort is that competing risks (death of other causes) have been recorded, allowing for survival analysis with competing risks. 

The GRI also contains multimodality. Therefore, part of the efforts of this study are related to data integration. 

Data cannot be shared, instead all the code is available in this repository.
